# Shuangyueliao Arcade

The hub page for the Shuangyueliao game collection: 23 free single-file HTML5
browser games. No installs, no ads-in-your-face, just play.

**Play:** https://shuangyueliao.github.io/game-arcade/

Single-file `index.html` — zero external assets (system fonts, inline SVG/CSS),
client-side genre filtering only, no tracking.
